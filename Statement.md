1. Project Overview

The Office Management & Employee Task Handling System (based on the uploaded Python script) is a console-based automation program that simulates daily office workflows. The system collects employee details such as name, role, and role code, then dynamically assigns tasks using conditional logic. Features include sales target calculations, technical-team duties, incentive computation, and automatic deadline generation.
The project demonstrates practical usage of Python classes, methods, user input handling, and date manipulation to mimic a real organizational environment.



---

2. Objective of the Project

The main objectives of the system are:

Automating fundamental office operations through Python scripting

Providing role-based task handling for employees

Generating dynamic outputs such as sales targets, technical responsibilities, and incentives

Demonstrating Object-Oriented Programming (OOP) by using classes for employees

Improving clarity in workflow management by automating instructions and deadlines




---

3. Problem Statement

In many traditional office environments, work allocation relies on verbal communication, manual reports, and fragmented task delegation. This often leads to:

Ambiguous responsibilities

Improper task tracking

Lack of automated incentives and performance metrics

Difficulty in ensuring deadlines

Inefficient coordination between departments


This project helps resolve these issues by creating a structured, automated system that assigns tasks based on employee roles, computes sales targets and incentives, and provides project deadlines automatically using Python logic and date utilities
